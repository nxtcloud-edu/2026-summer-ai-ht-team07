## 이 문서가 필요한 이유

우리 데이터는 합성이다. 그러므로 **"이 데이터가 왜 타당한가"** 가 곧 프로젝트의 신뢰도다.
그 답은 성능 수치가 아니라 이 문서에 있다.

동시에 이 문서는 `schema.py` 의 `monotone` 값과 `configs/data_gen.yaml` 의
가중치 부호가 **왜 그 값인지**에 대한 유일한 근거다. 둘 중 하나를 바꾸면 여기도 함께 고친다.

## 부호 규약 (가장 자주 틀리는 부분)

`head_vacuum`, `pin_vacuum`, `vacuum_status` 는 **음수 kPa 게이지압**이다.

```
진공이 강하다  =  값이 더 작다 (더 음수)   예: -70 kPa 이 -60 kPa 보다 강한 진공
```

따라서 "진공이 강할수록 성공률이 오른다"는 물리 관계는,
**부호 있는 값을 기준으로 하면 단조 감소(monotone = −1)** 로 표현된다.

> ⚠️ 이 부호를 놓치면 단조 제약 방향이 통째로 뒤집힌다.
> 학습은 조용히 성공하고 성능만 나빠지므로 끝까지 발견하지 못할 수 있다.
> `tests/test_contracts.py::test_vacuum_sign_convention` 이 이를 검사한다.

## 변수별 근거

### 1. UV 계열 — 테이프 점착력 제어

#### `uv_time` (UV 조사 시간, 3.0~7.0 s) — 제약 **+1**, 기여 **가장 큼**

다이싱 테이프의 점착제는 UV 조사를 받으면 가교(cross-linking) 반응으로 경화되어 점착력이 떨어진다.
점착력이 낮을수록 이젝터 핀이 다이를 떼어내기 쉬워진다.

- **방향**: 조사 시간 ↑ → 점착력 ↓ → 픽업 성공률 ↑ (단조 증가)
- **형태**: `sat` (포화형 tanh). 점착제가 완전히 경화되면 더 조사해도 추가 효과가 없다.
- **한계**: 과도한 조사는 잔사(residue)나 테이프 변형을 유발할 수 있으나,
  본 데이터의 범위(3~7초)는 정상 운전 구간이므로 역효과는 모델링하지 않았다.
  → **Q&A 대비**: "과조사 문제는 왜 없나요" 질문 시 이 범위 제한으로 답한다.
- **근거 출처**: _TODO(A)_

#### `uv_intensity` (UV 광량, 1000~1400 mW/cm²) — 제약 **+1**, 기여 **작음**

총 조사 에너지 = 광량 × 시간이므로 `uv_time` 과 동일한 메커니즘이다.
기여를 작게 잡은 이유는 **설비의 램프 출력 편차 범위가 좁기** 때문이다.
현장에서 실제로 조정하는 값은 시간이지 광량이 아니다.

### 2. 이젝터 핀 계열 — 박리 구동과 크랙 위험

#### `pin_speed` (핀 상승 속도, 0.8~1.6 mm/s) — 제약 **−1**

핀이 빠르게 올라올수록 다이에 걸리는 순간 굽힘 응력이 커진다. 다이는 실리콘 취성 재료라
응력이 임계를 넘으면 크랙 또는 치핑이 발생한다.

- **방향**: 속도 ↑ → 굽힘 응력 ↑ → 크랙 위험 ↑ → 성공률 ↓ (단조 감소)
- **상호작용**: `die_thickness` 와 곱셈 상호작용 (아래 상호작용 절 참조)
- **근거 출처**: _TODO(A)_

#### `pin_pressure` (핀 압력, 20~40 N) — 제약 **+1**

테이프-다이 계면을 박리시키는 직접적인 구동력이다.

- **방향**: 압력 ↑ → 박리 구동력 ↑ → 성공률 ↑ (포화형)
- **주의**: 압력이 과도하면 크랙이 난다는 반론이 가능하다. 본 모델에서는
  **크랙 위험을 속도와 높이 쪽으로 분리**해 모델링했다. 압력은 정적 하중이고
  속도는 동적 응력이라, 같은 크기라도 크랙 기여가 다르기 때문이다.
  → **Q&A 대비**: "압력이 크면 깨지지 않나요"에 위 논리로 답한다.
- **근거 출처**: _TODO(A)_

#### `pin_height` (핀 상승 높이, 0.3~0.7 mm) — 제약 **0 (내부 최적점)**

- 너무 낮으면 계면 박리가 시작되지 않는다.
- 너무 높으면 다이가 과도하게 굽어 파손된다.
- → **내부 최적점이 존재**하므로 단조 제약을 걸지 않는다 (설정 최적값 약 0.50 mm).

이 변수는 선형 모델이 원리적으로 잡을 수 없는 관계다.

## 상호작용 3종 — "왜 이 두 변수가 곱해지는가"

> 이 절은 **"왜 선형 모델로는 안 되는가"에 대한 답**이다. 발표에서 가장 자주 나올 질문이다.

### ① `pin_speed × die_thickness` — 부호 교차형

| | 얇은 다이 (100 µm) | 두꺼운 다이 (150 µm) |
|---|---|---|
| **느린 핀** | 안전 | 안전 |
| **빠른 핀** | ⚠️ **크랙** | 견딤 |

같은 핀 속도가 다이 두께에 따라 **정반대 결과**를 낸다.
곱셈항의 부호가 뒤집히므로 선형 모델은 원리적으로 재현할 수 없다.

**물리**: 굽힘 응력 σ ∝ (하중) / (두께²). 두께가 얇아지면 같은 하중에서도 응력이 급격히 커진다.

### ② `uv_time × tape_type` — 조건부 증폭형

UV 경화형 테이프(type=1)에서만 UV 조사 효과가 증폭된다. 일반 테이프(type=0)는 UV에 거의 반응하지 않는다.

```
tape_type = 0 :  UV 조사 시간을 늘려도 점착력이 거의 안 변함
tape_type = 1 :  UV 조사 시간에 점착력이 민감하게 반응
```

**설계상 중요**: 상호작용항이 `tape_type=0` 일 때 **0이 되도록** 구성했다.
그래야 `uv_time` 의 단조 증가 제약이 두 테이프 종류 모두에서 깨지지 않는다.

### ③ `runtime_hours × head_vacuum` — AND형 복합 악화

두 조건이 **동시에** 나쁠 때만 추가 손실이 발생한다.

```
콜릿이 마모됨  AND  헤드 진공이 약함   →  흡착 실패가 급증
둘 중 하나만 나쁨                      →  나머지가 보완
```

**현장 의미**: 진공이 약간 약해도 콜릿이 새것이면 버틴다. 그러나 마모된 콜릿에 약한 진공이
겹치면 급격히 나빠진다. 이것이 "왜 단일 변수 임계값 관리로는 부족한가"의 실제 사례다.
