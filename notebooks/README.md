# notebooks/ — 탐색 전용

## 규칙

1. **프로덕션 로직을 여기에 두지 않는다.**
   노트북에서 검증이 끝난 코드는 반드시 `src/yeda/` 아래 모듈로 옮긴 뒤 노트북에서는 import 해서 쓴다.
   앱과 학습 파이프라인은 노트북을 절대 import 하지 않는다.

2. **파일명에 담당자를 넣는다.** — `01_eda_C.ipynb`, `02_shap_check_D.ipynb`
   같은 노트북을 두 명이 동시에 고치면 git 충돌이 나는데, 노트북 충돌은 손으로 풀기가 매우 어렵다.
   파일을 나누는 것이 유일한 예방책이다.

3. **커밋 전 출력(output)을 지운다.**
   출력이 남은 노트북 diff 는 리뷰가 불가능하고 리포지토리를 무겁게 만든다.

   ```bash
   jupyter nbconvert --clear-output --inplace notebooks/*.ipynb
   ```

4. **발표 자료의 숫자는 노트북에서 인용하지 않는다.**
   반드시 `artifacts/metrics/` 의 산출물에서 가져온다. 노트북은 재실행 시점에 따라 값이 달라진다.
