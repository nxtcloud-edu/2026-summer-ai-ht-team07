## 왜 합성 데이터인가

반도체 후공정의 실공정 데이터는 **기밀 이슈로 외부 접근이 불가능**하다.
공개 데이터셋 중 다이 픽업 공정을 다루는 것은 존재하지 않는다.

따라서 다음 방법론을 택했다.

1. 공개 논문·설비 사양서에서 **변수와 정상 운전 범위** 수집
2. 반도체 후공정 30년 이상 현직자 면담으로 **물리적 방향·상대적 크기·상호작용** 정의
3. 확률적 라벨 생성 (결정론적 규칙 아님)
4. 홀드아웃 분리로 검증

이는 실데이터를 흉내 낸 것이 아니라, **문헌과 도메인 지식으로 명시적으로 설계한 데이터**다.
근거는 `docs/PHYSICS_RATIONALE.md` 에 변수 단위로 기록되어 있다.

## 생성 절차

```
① 조건 샘플링    설정점 중심 정규분포 65% + 범위 균등분포 35%
                 (양산 로트 + 조건 탐색 로트를 모사)
        ↓
② 잠재 점수      13개 변수 기여 + 상호작용 3개
        ↓
③ 확률 변환      p = sigmoid(intercept + scale × 잠재점수)
        ↓
④ 라벨 샘플링    y ~ Bernoulli(p)    ← 동일 조건에서도 결과가 갈린다
        ↓
⑤ 센서 노이즈    관측값에만 노이즈 + 분해능 반올림
                 (참값과 관측값의 괴리 = 환원 불가능한 오차)
        ↓
⑥ 결측 삽입      1~3% MCAR
```

**③④가 핵심이다.** 라벨이 확률적이므로 완벽한 모델조차 100%를 낼 수 없다.
이론적 상한(베이즈 정확도)은 약 0.87이며, `artifacts/metrics/data_generation.json` 에 기록된다.

## 검증

`tests/test_generator.py` 가 다음을 자동 검사한다.

| 테스트 | 검사 내용 |
|---|---|
| `test_label_is_not_deterministic` | 베이즈 정확도 < 0.95 (결정론 회귀 방지) |
| `test_no_single_rule_reproduces_target` | 어떤 단일 임계값도 정확도 90% 미달 |
| `test_all_features_contribute` | 13개 변수 전부가 기여 (순수 난수 없음) |
| `test_interactions_present` | 상호작용 2개 이상 작동 |
| `test_monotonicity_matches_schema` | 생성 방향이 단조 제약과 일치 |
| `test_values_are_rounded` | 분해능 반올림 (소수점 9자리 잔여 없음) |
| `test_class_balance` | 성공률 65~80% |

## 한계

1. **실공정 검증 미완료** — 절대 성능 수치를 실공정에 그대로 적용할 수 없다.
2. **단일 설비 가정** — 설비별 편차, 로트 간 변동을 반영하지 않았다.
3. **시간적 구조 없음** — 각 행이 독립이다. 실제로는 연속 생산의 시계열 상관이 있다.
4. **결측이 MCAR** — 실제 설비 로그의 결측은 센서 고장 등과 상관된 MNAR일 가능성이 높다.
5. **저습 정전기 미모델링** — 습도 하한이 30 %RH 이므로 해당 구간 문제를 다루지 않는다.
6. **UV 과조사 역효과 미모델링** — 범위(3~7초)를 정상 운전 구간으로 제한했다.

> 위 한계는 모두 **의도적 범위 제한**이며, README 와 발표에서 먼저 밝힌다.
